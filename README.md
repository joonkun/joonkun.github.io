# joonkun.github.io

Joon(허재준)의 개인 사이트. [Monograph](https://github.com/xocothemes/monograph) 테마(MIT, Andrei Alba)를 바탕으로 만들었다.

- 글: `src/content/posts/<slug>/index.md` (`category`: 제품, AI, 노트)
- 사이트 정보: `src/config/site.ts` (`launched: false`인 동안 검색엔진 차단)
- `main`에 올리면 GitHub Actions가 GitHub Pages로 배포한다.
